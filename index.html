私藏食譜本

一個用來收藏自己喜歡的食譜的地方。
每道菜都有詳細的材料與步驟，可以直接在廚房邊看邊做。
支援手機安裝，離線也能瀏覽。

📋 新增食譜格式

把以下格式貼給 AI，AI 會自動轉換成 JSON 加入 recipes.js：

【菜名】xxx（subtitle） 【描述】一兩句介紹 【分類】便當 / 湯品 / 點心 【標籤】快速, 微波料理, 日式 【時間】10 分鐘 【難度】簡單 / 中等 【份量】1 人份 【圖片】images/xxx.png 【材料】 - 食材名稱：份量（加☆代表調味料） - 牛奶：2 大匙 ☆ 【作法】 1. 步驟一 2. 步驟二 【小撇步】選填，額外備註

📱 安裝到手機

用 Safari（iOS）或 Chrome（Android）開啟網頁後，
點選「分享」→「加入主畫面」即可安裝成 App。
安裝後可以離線瀏覽所有食譜。

⚡ 互動功能

進入食譜詳情頁後：
• 點擊食材 → 打勾已準備好的材料
• 點擊步驟 → 追蹤烹飪進度
• ☆ 標記 = 調味料類
