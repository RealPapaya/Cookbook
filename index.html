私藏食譜本

一個用來收藏自己喜歡的食譜的地方。
每道菜都有詳細的材料與步驟，可以直接在廚房邊看邊做。
支援手機安裝，離線也能瀏覽。

📋 新增食譜格式（貼給 AI 即可）

【菜名】xxx（subtitle） 【描述】一兩句介紹 【國籍料理】日式 / 韓式 / 中式 / 義式 / 法式 / 泰式 / 美式 / 台式 【分類】便當 / 湯品 / 炒菜 / 點心 / 早餐 【主食類型】麵條 / 飯 / 湯品 / 點心 【標籤】快速, 微波料理, 辣, 清淡 【時間】10 分鐘 【難度】簡單 / 中等 / 困難 【份量】1 人份 【材料】 ← 格式: 名稱：數量 單位 [標籤1,標籤2] (☆=調味料) - 冷凍烏龍麵：1 塊 [主食] - 牛奶：2 大匙 [乳製品] ☆ - 黑胡椒：適量 [香料] ☆ 【作法】 1. 步驟一 2. 步驟二 【小撇步】選填備註

🌍 支援國籍料理分類

日式 🇯🇵｜韓式 🇰🇷｜中式 🇨🇳｜義式 🇮🇹｜法式 🇫🇷｜泰式 🇹🇭｜美式 🇺🇸｜台式 🇹🇼｜日義融合｜其他

📱 安裝到手機

iOS Safari → 分享 → 加入主畫面
Android Chrome → 選單 → 安裝應用程式
安裝後可離線瀏覽所有食譜。

⚡ 互動功能

• 點擊食材 → 打勾已準備材料
• 點擊步驟 → 追蹤烹飪進度
• ＋ / − 按鈕 → 調整份量，自動換算所有食材數量
• ⚙️ 篩選按鈕 → 多維度搜尋（國籍、主食、標籤、食材類別）
